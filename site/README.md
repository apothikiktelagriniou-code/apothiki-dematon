# Ιστοσελίδα — Αποθήκη Δεμάτων ΚΤΕΛ Αγρινίου

Στατική ιστοσελίδα, χωρίς βάση και χωρίς πρόσθετα. Κόστος λειτουργίας: μόνο το domain.

## Πού αλλάζω τι

| Θέλω να αλλάξω | Αρχείο |
|---|---|
| Τιμές, προορισμούς, ωράριο, τηλέφωνα, φύλαξη, παράδοση στο σπίτι | `site/src/data.mjs` |
| Συχνές ερωτήσεις | `site/src/faq.mjs` (`FAQ` και `FAQ_EN`) |
| Κείμενα σελίδων | `site/src/pages/*.html` (ελληνικά), `site/src/pages-en/*.html` (αγγλικά, στο `/en/`) |
| Αγγλικά ονόματα πόλεων και κείμενα δεδομένων | `site/src/en.mjs` (το τεστ φωνάζει αν λείπει κάτι) |
| Επιβάρυνση βάρους | `OVERWEIGHT` στο `site/src/data.mjs` |
| Χρώματα, γραμματοσειρές | `site/src/assets/site.css` (πάνω πάνω) |
| Δρομολόγια | `src/schedule-seed.js` της εφαρμογής |

Μετά από αλλαγή: `node site/build.mjs` → τα έτοιμα αρχεία βγαίνουν στο `site/dist/`.
Κείμενο με όλους τους προορισμούς/τιμές: `node site/export-text.mjs > Προορισμοί_και_τιμές.txt`.

## Έλεγχοι

`node --test site/tests/calc.test.mjs` — υπολογιστής, κατηγορίες μεγέθους, φύλαξη, δρομολόγια.

## Πριν τη δημοσίευση

1. Στο `build.mjs`: `PROTOTYPE = false` (φεύγει η κίτρινη μπάρα, ανοίγει το robots.txt στη Google).
2. Να τρέξει το `supabase/migrations/0022_track_rate_limit.sql` (όριο αναζητήσεων).
3. Όλα τα σημεία «Εκκρεμεί» / «Προς έλεγχο» στις σελίδες.
4. Domain και φιλοξενία (προτείνεται δωρεάν: GitHub Pages ή Cloudflare Pages), Search Console, στατιστικά χωρίς cookies.

## Αναζήτηση δέματος

Η σελίδα καλεί τη συνάρτηση `track_parcel` του Supabase με το δημόσιο κλειδί (το ίδιο με την εφαρμογή).
Επιστρέφει μόνο κατάσταση, ώρα, πόλη προέλευσης/προορισμού και τεμάχια — ποτέ όνομα ή τηλέφωνο.
